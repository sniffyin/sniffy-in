# Blog cover image shot list (30 posts, 1 unique cover each)

## Buying and file rules
- **Size:** landscape, minimum 1600 x 900 px (16:9). Cards crop with `object-cover`, so keep the subject in the centre 60%.
- **Format:** buy JPG, then export as WebP (about 1200 px wide, under 150 KB) and keep a 800 px version. Name each file exactly as in the "Save as" column. These are descriptive, keyword-based names (lowercase, hyphens, no spaces or underscores), which Google reads as an image signal. Also keep an `-800.webp` copy for cards, e.g. `persian-cat-lion-cut-clipped-body-fluffy-mane-800.webp`.
- **Licence:** commercial web use, no watermark. Prefer "extended" if the site offers it.
- **Species/breed must match the post.** The text in the post is the source of truth.
- **Prefer:** natural light, home/indoor settings, Indian home interiors if you can find them. Avoid: salon cages, muzzles, harsh restraint, visibly distressed animals, and any text or brand logos in the frame.
- **Rename before upload:** stock sites give names like `istock-123456.jpg`. Rename every file to the descriptive name below first.
- **Alt text:** write it from the "Shot" column when wiring (e.g. "Persian cat being brushed on a sofa"). Alt text matters more than the filename, so I'll add it for all 30.

Save all files in `public/images/blog/`.

## Optional: extra in-body images
The blog system currently supports only one cover image per post. If you want inline photos too, a new `image` block type would be needed in `blogPosts.ts`, `BlogsPage.tsx` and `prerenderSpa.ts`. Best candidates for a second image each:
- Persian lion cut: before and after
- Shih Tzu haircut styles: one photo per style (puppy, teddy bear, summer, long)
- Pomeranian: a safe scissor cut vs a shaved coat
- Golden/Lab: a deshedding rake with fur
- Ear infection, tick and nail-trim posts: a close-up demonstration
