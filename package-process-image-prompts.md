# Package process images — ChatGPT prompts (3 packages)

Goal: for each package, a numbered photo series (1, 2, 3 …) showing a male groomer doing exactly what the package includes, nothing more.

## How to use (important for consistency)
1. Open a **new ChatGPT chat per package** (so the dog + groomer stay identical across that package's images).
2. Paste the **MASTER STYLE BLOCK** first, send it, and wait for ChatGPT to confirm.
3. Then paste the steps **one at a time**, in order. If a face or the dog drifts, reply: *"Keep the exact same groomer, same dog, same apron and same home as image 1. Redo this step."*
4. Save as `spa-bath-1.jpg` … `spa-bath-8.jpg`, `haircut-1.jpg` …, `combo-1.jpg` … and send me the folder; I'll wire them into the package cards.
